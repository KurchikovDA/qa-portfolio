# QA Portfolio: Denis Kurchikov

[Русская версия](README.ru.md)

QA engineer with game testing experience: two years at Owlcat Games (functional, regression and localization testing, cross-platform certification for PC / PlayStation / Xbox / Nintendo Switch).

This repository contains case studies and documentation samples that show how I test, report bugs and reason. The cases are based on real hands-on game testing tasks; company names are not disclosed. Each document is available in English and Russian.
