# QA-портфолио: Денис Курчиков

[English version](README.md)

QA-инженер с опытом тестирования игр: два года в Owlcat Games (функциональное, регрессионное и локализационное тестирование, кроссплатформенная сертификация PC / PlayStation / Xbox / Nintendo Switch).

Здесь собраны кейсы и примеры документации, которые показывают, как я тестирую, оформляю баги и рассуждаю. Кейсы основаны на реальных практических задачах по тестированию игр; названия компаний не указываются.

## Документы

| Документ | Что внутри |
|---|---|
| [LQA-кейс: русская версия ММОРПГ](ru/Kurchikov_LQA_Case_MMORPG.pdf) | Лингвистическое и функциональное тестирование 21-минутного пролога по видео: отзыв, 18 лингвистических замечаний и 8 функциональных проблем с таймкодами и цветовой разметкой по серьёзности. Баг-репорт по игровой механике, найденный покадровым замером полосы здоровья. |
| [QA-кейс: многопользовательский военный симулятор](ru/Kurchikov_QA_Case_Military_Simulator.pdf) | Три задачи: баг-репорты по видео со скриншотами, чек-лист шоустопперов для прокачки экипажа, тест-кейсы по приоритету для нового визуального эффекта. |
| [Примеры QA-документации](ru/Kurchikov_QA_Documentation_Samples.pdf) | Баг-репорт с полным набором атрибутов, чек-лист с пятиуровневой шкалой серьёзности, тест-кейсы с четырёхуровневой шкалой приоритета. Данные вымышленные. |
| [QA: вопросы и ответы](ru/Kurchikov_QA_Questions_and_Answers.pdf) | 59 вопросов из технических тестов по 9 темам (основы, тест-дизайн, веб и сеть, мобильное тестирование, API, автоматизация и CI/CD, Python) с ответами и объяснением логики, плюс задача на код с автотестами на pytest. |

Редактируемые версии в Word лежат в папке [source](source).
